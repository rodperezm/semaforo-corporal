# MetricBody

App web instalable para registrar peso, IMC, medidas corporales (tórax, cintura, abdomen, cadera) y % de grasa con caliper (Jackson-Pollock 3 pliegues + Siri), con semáforo verde/amarillo/rojo, composición corporal, gráficos e historial.

**Usar:** https://rodperezm.github.io/semaforo-corporal/

**Instalar en iPhone:** abrir el enlace en Safari → botón Compartir → "Agregar a pantalla de inicio".

Los datos se guardan en el dispositivo (localStorage). La app funciona sin conexión después de la primera carga.
